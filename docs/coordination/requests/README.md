# Förfrågningar

Ögonblicksbild 8 november 2026 (Europe/Stockholm). Ingång: [../README.md](../README.md). Mall: [../REQUEST-TEMPLATE.md](../REQUEST-TEMPLATE.md). Flöde: [../WORKFLOW.md](../WORKFLOW.md).

Katalogen är tom med avsikt. Här ska bara riktiga förfrågningar ligga, efter att David godkänt att just den filen får skrivas till `DavidDast/HOPESI`. Inga exempelärenden och inga syntetiska uppdrag får läggas här för att visa mallen.

En fil i den här katalogen ska ha status `proposed`. David kan godkänna en åtgärd i chatten utan att filen själv blir ett godkännande. Filen startar inte arbete, väcker ingen agent och ger ingen rätt att handla. Ingen pollning läser katalogen.

Första kontakt dirigerar när David lämnat vidare ärendet i chatten. Terminal-AI som inte har skrivgodkännande ger i stället David en kopierbar text.
